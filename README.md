# Trip Mate – Smart Trip Planning Application

Trip Mate is a UI/UX-based smart travel planning application prototype designed using Figma.

## Features
- Trip itinerary planning
- Travel recommendations
- Budget planning
- User-friendly interface

## Tools Used
